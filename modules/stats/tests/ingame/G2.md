# G2 in-game check: co-save persistence and actor lifecycle

Steps for the `in-game` and `log` verification of [G2](../../../../docs/stats/PLAN.md#g2-co-save-persistence-and-actor-lifecycle). They run from the main session only ([CLAUDE.md#workflow](../../../../CLAUDE.md#workflow)).

There is no API to change a stat in game yet (A1), and G3 does not apply the AvDeltas yet, so the check reads the plugin log: the `AvDelta` lines and the contributions show what the pools would get.

## Setup

- **Test DLL:** configure the plugin build with the test hooks, build, and set the option back afterwards:

  ```sh
  cmake -B build/plugin -DTOM_STATS_TEST_HOOKS=ON && cmake --build build/plugin
  cmake -B build/plugin -DTOM_STATS_TEST_HOOKS=OFF && cmake --build build/plugin
  ```

  The test DLL logs everything the service holds for the player (`Test <when>: ...` lines) after each load, new game and race change. While `Data/SKSE/Plugins/trials-of-mastery-stats-test-change.txt` exists, it also sets this change on the player after each load ([TestHooks.cpp](../../plugin/src/TestHooks.cpp)): STR base adjustment `TrialsOfMasteryStatsTest:G2` +3, DEX accumulated 3, active 2, XP 42.5, CON modifier `TrialsOfMasteryStatsTest:G2` +4, 2 pending points, r 1.5. Setting it again changes nothing.
- **Mod folder** (laid out like `Data/`): the test DLL, the shipped INI and the shipped tables under `SKSE/Plugins/trials-of-mastery/data/stats/`, no other patches.
- **Patches**, each copied into `SKSE/Plugins/trials-of-mastery/data/stats/stats/` only for the run that names it:
  - `g2-race.json`: CON +2 for each of the ten playable races, `{"CON": {"raceAdjustments": {"NordRace": 2, "ImperialRace": 2, ...}}}`.
  - `g2-default-base.json`: `{"STR": {"base": 12}}`.
- **Plugin-free mod folder:** an empty `SKSE/Plugins/`.

The default tables have no race adjustments, so a player of any race starts at base 10 everywhere.

## Runs

Each run starts the game in `qasmoke` and ends with a stop. The lines are in `Documents/My Games/Skyrim Special Edition/SKSE/trials-of-mastery-stats.log`. Every load logs `Co-save: revert on thread …`, then `Co-save: loading on thread …` and `SKSE message kPostLoadGame (…)`, `After the load on thread …`.

1. **Base save.** Test DLL, marker file present.
   - `save tomg2base`: `Co-save: wrote record STAT version 1, format version 1, 0 actors, … bytes` (a game started with `coc` from the main menu fires no kNewGame, so the player has no stats yet).
   - `load tomg2base`: `Co-save: read record STAT version 1, format version 1, 0 actors restored, 0 dropped`; `After the load: 0 saved actors, races renewed for 1`; `Test change applied, 0 errors`; `AvDelta test change: actor 00000014 …` for AttackDamageMult +0.03, CarryWeight +6, Health +20, HealRate, MagickaRate and StaminaRate +0.08 each, PoisonResist and ResistDisease +2 each (up to float rounding); `Test after the load: player 00000014, race <race>, multiplier 1, r 1.5, N 5, pending points 2`, `STR base 13 [TrialsOfMasteryStatsTest:G2 +3], default base 10, …`, `DEX base 10 [], default base 10, accumulated 3, active 2, xp 42.5, …`, `CON … modifiers [TrialsOfMasteryStatsTest:G2 +4]`, and a `contributions [...]` line with those amounts.
   - `save tomg2a`: `wrote record STAT version 1, format version 1, 1 actors`.
2. **Values survive save, quit and load.** Test DLL, marker file removed.
   - `load tomg2a`: `1 actors restored, 0 dropped`, no `Test change applied`, and the same `Test after the load` lines as at the end of run 1, no `AvDelta` lines.
   - `load tomg2base`: `0 actors restored`, and the player is back at the defaults: `r 2, N 5, pending points 0`, every stat at base 10 with no keys, empty modifiers. This is the revert of a load; the revert of a new game is in the manual checks.
3. **Without the plugin.** Plugin-free mod folder. `load tomg2a`, `save tomg2noplugin`. No crash, no crash log.
4. **Back with the plugin.** Test DLL, marker file removed. `load tomg2noplugin`: no crash; either no `Co-save: read record` line and the player at the defaults (`After the load: 0 saved actors, races renewed for 1`), or, if SKSE kept the plugin's record, `1 actors restored` with the values of run 1. Both pass; note which one it was.
5. **Patched race adjustment.** Test DLL, marker file removed, `g2-race.json` in place.
   - `load tomg2a`: `AvDelta after the load: actor 00000014` Health +10, HealRate, MagickaRate and StaminaRate +0.04 each, PoisonResist and ResistDisease +1 each; `CON base 12 [TrialsOfMasteryStats:Race +2]`, still with the `+4` modifier; STR still 13; the contributions for Health go from 20 to 30.
   - `player.setrace ElderRace`, a race the patch leaves out: `race switch: actor 00000014 on thread …`, then `race switch: actor 00000014 is of race ElderRace` and the same `AvDelta` amounts negated, and `CON base 10 []`.
   - `player.setrace <race of the player from the Test lines>`: the amounts of the first step again, `CON base 12 [TrialsOfMasteryStats:Race +2]`.
6. **Patched default base.** Test DLL, marker file removed, `g2-default-base.json` in place (and `g2-race.json` gone). `load tomg2a`: no `AvDelta` lines; `STR base 15 [TrialsOfMasteryStatsTest:G2 +3], default base 12`; the contributions as at the end of run 1 (multiplier 1, assumption 13).
7. **Release log.** Release DLL. `load tomg2a`: the `Co-save` lines with the record and format versions and the actor count as above, no `Test` lines.

## Manual checks

The bridge cannot start a new game or pick a race in the race menu, so these run by hand:

- **A new game resets the values.** Test DLL, marker file removed. Load `tomg2a`, then start a new game from the main menu and finish character creation. Expect `Co-save: revert`, `SKSE message kNewGame (…)`, `New game on thread …`, `New game: player 00000014 of race <race>`, `Test new game: … r 2, N 5, pending points 0` with every stat at base 10, and after the race menu closes `race menu closed: actor 00000014 on thread …`. Note whether `race switch` lines appear while the race menu is open.
- **A new character of a race with an adjustment.** As above with `g2-race.json` in place. The `AvDelta` lines of the new game, the race switches and the race menu closing add up to Health +10, HealRate, MagickaRate and StaminaRate +0.04 each and PoisonResist and ResistDisease +1 each, which is `curve(2) − curve(0)` of each CON effect, and the last `Test` lines show `CON base 12 [TrialsOfMasteryStats:Race +2]`.
